Tracing one step through vanilla TEM

One call to iteration() — everything that happens for a single environment step. A training rollout calls this n_rollout = 20 times before one gradient update; a 5000-episode run calls it on the order of 100,000 times. This page freezes just one of those calls and walks through it. No value mechanism here — this is plain TEM, the substrate TEM-R builds on.
